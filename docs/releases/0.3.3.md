# 0.3.3 · 会话定位、忽略与附件缓存修复

- 风险弹窗和并发请求列表显示项目名、完整工作目录、会话标题与 ID，帮助定位具体受影响的会话；缺元数据时明确回退。
- “生成精简副本”按钮改为“忽略该会话”。保存成功且候选仍有效后继续当前请求，随后持续跳过这个会话的发送前检查；重启保留，可在看板会话明细或设置中恢复。其他、父、子和新副本不会自动继承，统计与历史告警保留。精简副本界面移除，历史回执保留。
- 修复 image/file 内容使大上下文每一步重复要求确认的问题：历史与实时请求共用 sha256 内容 ID 投影，图片按 base64 字节长度加权、文件按 handle 文本比较。缺 ID 仍保持未知；升级分析器与适配器版本，使旧 facts 自动失效并重建。
- 修复 Windows 0666 权限模式使有效事实缓存被读取/初始化删除的问题：POSIX group/world 权限位检查仅在非 Windows 执行。

兼容范围仍为 DSH `>=0.2.1-rc.2 <0.3.0-0`，Node `^22.19.0 || >=24.0.0`。测试使用真实宿主运行时、合成 Session 与本机假上游；Windows 权限路径为模拟回归，未进行 Windows 真机验收。附件重编码、执行环境路径、Files API 和服务端视觉 token 仍属于估计边界。

不新增模型工具或 system 提示，不自动调用摘要模型。安装和重启安排在任务间隙：备份 profile 与插件状态，安装本版冻结包并刷新页面。忽略偏好存储于 web-state v2，可读取旧 v1；需要回滚时使用原 0.3.2 冻结包与备份，旧版不继承 v2 的忽略/收起偏好。升级、回滚均不删除 Session 真源。

GitHub Release 与 npm 使用同一冻结 tgz，npm 由 GitHub Actions Trusted Publishing/OIDC 完成；各渠道与本机安装状态分别核验。
