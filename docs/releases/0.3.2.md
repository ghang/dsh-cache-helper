# 0.3.2 · npm trusted publishing

This maintenance release adds a GitHub Actions OIDC publisher. After the
package's one-time trusted-publisher binding, publishing a GitHub Release sends
the same frozen tarball to npm without a long-lived publishing token or a
per-release website authentication step.

The job checks the personal annotated tag, successful Node 22/24 CI for the
exact source SHA, the GitHub server SHA-256 digests, SHA256SUMS, and package
identity. It uses this repository's existing two-asset format:
`dsh-cache-helper.tgz` and `SHA256SUMS`. Matching existing npm versions are
verified without another upload; latest propagation is awaited with a bound.

Runtime code, data formats, configuration and send-control behavior remain as
in 0.3.1. Keep the existing profile/storage backup when upgrading, and use the
original 0.3.1 frozen package for rollback. The workflow file and version bump
alone do not prove that npm publication or a daily installation has completed.
